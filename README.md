# SNS情報拡散・感情可視化Webアプリ

卒業研究と就職活動用ポートフォリオとして開発しているWebアプリです。
SNS投稿の地理的・時間的な分布、情報拡散のネットワーク、
YouTubeコメントの感情分析結果を可視化することを目指しています。

## 実装状況

### ① SNS投稿の地理的・時系列可視化：基本版を実装

- Mapbox GL JSによる投稿位置の表示
- 直近30分間の投稿を表示
- 再生・停止
- 時間スライダー
- 再生速度の変更
- 先頭へのリセット
- 点のクリックによる投稿日時の表示

### 今後の実装予定

- ② SNS情報拡散のネットワーク・時系列可視化
- ③ YouTubeコメントの感情分析結果の可視化

## 使用技術

- Python・pandas：データ確認、抽出、加工
- JavaScript・HTML・CSS：Web画面と時間操作
- Mapbox GL JS：地図表示
- Vite：開発サーバー、公開用ビルド

## データ

UCI Machine Learning Repositoryの
「Twitter Geospatial Data」を使用しています。

- 元データ：米国本土の位置情報付きツイート14,262,517件
- 元データの期間：2013年1月12〜18日（CST）
- 現在の表示対象：ニューヨーク周辺の34,260件
- 対象期間：2013年1月12日 00:00:00〜23:59:59（CST、UTC−6）
- 抽出範囲：経度 −74.3〜−73.6、緯度 40.4〜41.0

抽出範囲は緯度・経度による矩形で、ニューヨーク市の行政区域ではありません。

元データを地域・期間で抽出し、日時をUTCに変換してGeoJSON化しました。
時間操作には、対象期間の開始からの経過秒数を使用しています。
表示時刻はCSTで、ニューヨーク現地時間（当該期間のEST）より1時間遅れます。

投稿本文やリツイート関係は含まれていません。
この画面は投稿位置の分布と時間変化を示すもので、
投稿間の情報拡散経路を示すものではありません。
また、位置情報付き投稿の分布であり、SNS利用者全体を代表するものではありません。

## ローカルでの起動

Node.jsとnpmが必要です。

1. webフォルダで依存パッケージをインストールします。

   ```powershell
   cd web
   npm.cmd ci
   ```

2. webフォルダに.env.localを作成し、
   自分のMapbox公開用トークンを設定します。

   ```text
   VITE_MAPBOX_ACCESS_TOKEN=自分の公開用トークン
   ```

   pk.から始まる公開用トークンを使用してください。
   この値はブラウザに配信されます。

3. 開発サーバーを起動します。

   ```powershell
   npm.cmd run dev
   ```

4. ターミナルに表示されたLocalのURLをブラウザで開きます。
